# Campus Shuttle Network Optimization – Dresden

This project develops and evaluates an optimized campus shuttle
network for TU Dresden using mathematical optimization in GAMS.

The project consists of two main optimization problems:

1. Route Network Planning
2. Line Network Planning

## Objectives

- Minimize passenger travel time
- Minimize construction and usage costs
- Evaluate different bus capacities
- Optimize the network under budget constraints
- Analyze network modifications and route diversions
- Determine an efficient number of shuttle lines

## Tools

- GAMS
- Mathematical Optimization
- Network Optimization
- Data Analysis
